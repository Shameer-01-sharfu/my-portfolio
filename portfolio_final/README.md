# Shameer S — Accessible Responsive Portfolio

- Semantic HTML5: header, nav, main, section, article, aside, footer
- Skip link and keyboard-friendly navigation
- Accessible labels, focus states, live validation messages and ARIA attributes
- SEO metadata, canonical URL, Open Graph metadata and JSON-LD
- Multi-page structure: Home, About, Projects, Skills, Contact

## Task 2
- CSS Grid for page and project layouts
- Flexbox for navigation, actions and tags
- Mobile-first responsive breakpoints for mobile, tablet and desktop
- CSS custom properties for theme tokens
- Light/dark mode with saved preference
- Reduced-motion support and print styles
