SHA Store

A production-style e-commerce product catalog demonstrating modular frontend architecture, client-side routing, optimized assets and deployment-ready configuration.

Architecture

Capstone implementation

Modular frontend

Product data, application state, rendering, routing and UI actions are separated into focused JavaScript modules.

Client-side routing

Hash-based routes provide seamless Home, Products, Product Details and Cart navigation without full-page reloads.

Performance

Responsive CSS, optimized Pexels CDN product images, lazy loading, async decoding and a small dependency-free JavaScript bundle keep the app lightweight.

Deployment ready

Static hosting configuration is included for Vercel and Netlify, with a production build that can also be served by Render.

Product photography: Pexels free-to-use images, loaded through the Pexels CDN.
